配置指引

视频教程 · GitHub 仓库地址

  1. 在本页上方的“AI 模型平台”区域，点击 + 添加平台。
  2. 填写平台名称、API Base URL、API Key 与模型名称。支持 OpenAI 兼容协议，例如 OpenAI / DeepSeek / Qwen / GLM / Kimi / MiniMax / Mimo / Opencode Go / OpenRouter / Stepfun / ModelScope / Ollama 等。
  3. 填写完成后，点击平台条目右侧的 测试 按钮验证配置；连接成功后会自动保存，无需再点击底部“保存设置”。若需手动保存全部设置，仍可使用底部按钮。
